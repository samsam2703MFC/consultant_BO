# Instrukcja: ewidencja opakowań BDO przy wysyłkach

Instrukcja opisuje przygotowanie zestawienia opakowań dla wysyłki WDT.

## Gdzie znajdują się funkcje BDO

- Aby pracować z konkretną wysyłką, w menu po lewej stronie wybierz: **Dokumenty → Wysyłki (wygenerowane)**.
- Aby uzupełnić dane materiałów opakowaniowych na przyszłość, wybierz: **Audyty → Dane opakowań BDO**.

## Zanim zaczniesz

System liczy opakowania na podstawie receptury produktu oraz dokumentu WZ.

- Produkt musi mieć recepturę.
- Materiał użyty jako opakowanie musi być oznaczony jako **część opakowania**.
- Dla opakowania liczonego w sztukach, np. kartonu, potrzebna jest masa jednej sztuki w gramach.
- Dla materiału liczonego w gramach, np. folii, masa wynika bezpośrednio z receptury. Nie wpisuj wtedy masy jednej sztuki.

## 1. Jak sprawdzić ewidencję dla wysyłki

1. W menu po lewej stronie otwórz **Dokumenty → Wysyłki (wygenerowane)**.
2. W razie potrzeby użyj filtra po kliencie lub dacie.
3. W kolumnie **BDO** sprawdź status:

   - **Kompletna** — dane są gotowe.
   - **Braki: X** — czegoś brakuje i trzeba to uzupełnić.
   - **Brak ewidencji** — dla tej wysyłki nie utworzono jeszcze zestawienia.
   - **Dane bieżące** — ewidencja historycznej wysyłki została wyliczona z aktualnej receptury i aktualnych danych opakowań, a nie z danych z dnia wysyłki.

4. Kliknij **PDF**, aby pobrać zestawienie opakowań.

## 2. Jak uzupełnić brakujące dane BDO przy wysyłce

1. W menu po lewej stronie otwórz **Dokumenty → Wysyłki (wygenerowane)**.
2. Przy wysyłce ze statusem **Braki** kliknij **Uzupełnij**.
3. W oknie wybierz pozycję, którą chcesz poprawić. Zobaczysz produkt, materiał opakowaniowy i informację, czego brakuje.
4. Uzupełnij:

   - **kategorię BDO**,
   - **rodzaj użycia**,
   - **masę jednej sztuki w gramach** — tylko jeśli materiał jest liczony w sztukach.

5. Pole **Zapisz te dane także w kartotece surowca** jest domyślnie zaznaczone.

   Zostaw je zaznaczone, jeśli chcesz używać tych samych danych przy następnych wysyłkach zawierających ten materiał.

6. Jeżeli materiał ma już zapisane dane, system zapyta, czy chcesz je nadpisać.

   - Wybierz **OK**, gdy nowe dane są poprawniejsze.
   - Wybierz **Anuluj**, gdy chcesz poprawić wyłącznie tę jedną wysyłkę, bez zmiany danych surowca.

7. Kliknij **Zapisz dane BDO**.

Jeśli w wysyłce był tylko jeden brak, status zmieni się na **Kompletna**. Jeśli braków jest więcej, powtórz czynność dla kolejnej pozycji.

## 3. Jak wybrać kategorię BDO

Wybierz materiał, z którego wykonany jest element opakowania:

| Przykład opakowania | Kategoria BDO |
| --- | --- |
| Folia, worek, plastikowa tacka | Tworzywa sztuczne |
| Karton, tektura, papierowa etykieta | Papier i tektura |
| Paleta lub drewniana przekładka | Drewno |
| Butelka lub słoik | Szkło |
| Puszka aluminiowa | Aluminium |
| Stalowa puszka lub element ze stali | Metale żelazne |
| Jeden nierozłączny materiał z kilku warstw | Wielomateriałowe |
| Materiał niewymieniony wyżej | Pozostałe |

Jeżeli dwa elementy można rozdzielić, np. karton i folię, wpisz je jako dwa oddzielne materiały opakowaniowe.

## 4. Jak utworzyć ewidencję dla starszej wysyłki

W menu po lewej stronie otwórz **Dokumenty → Wysyłki (wygenerowane)**. Przy starszej wysyłce możesz zobaczyć status **Brak ewidencji**.

1. Kliknij **Utwórz ewidencję**.
2. Przeczytaj komunikat ostrzegawczy.
3. Potwierdź tylko wtedy, gdy akceptujesz wyliczenie z danych, które są w systemie teraz.

Tak utworzony dokument będzie oznaczony jako **Dane bieżące**. PDF również zawiera tę informację.

## 5. Jak poprawić dane materiałów przed kolejną wysyłką

1. W menu po lewej stronie wybierz **Audyty → Dane opakowań BDO**.
2. Lista pokazuje produkty i materiały, którym brakuje danych.
3. Kliknij **Uzupełnij dane BDO** przy wybranym materiale.
4. Wpisz kategorię, rodzaj użycia oraz — jeśli materiał jest liczony w sztukach — masę jednej sztuki.
5. Zapisz.

To rozwiązanie jest dobre, gdy chcesz poprawić dane raz, zanim utworzysz kolejne wysyłki.

## 6. Najczęstsze komunikaty

| Komunikat | Co zrobić |
| --- | --- |
| Brak receptury | Poproś osobę odpowiedzialną za produkt o uzupełnienie receptury. |
| Brak elementu opakowania w recepturze | Sprawdź, czy materiał opakowaniowy jest dodany do receptury i oznaczony jako część opakowania. |
| Brak kategorii BDO | Wybierz kategorię materiału. |
| Brak rodzaju użycia | Wybierz jednorazowe albo wielokrotnego użytku. |
| Brak masy jednej sztuki | Dla kartonu, palety itp. wpisz masę jednej sztuki w gramach. |

## Dobra praktyka

- Uzupełniaj dane opakowania od razu, gdy pojawia się nowy karton, folia lub paleta.
- Jeśli nie znasz masy opakowania, poproś o dane osobę odpowiedzialną za zakupy, technologię lub dostawcę opakowania.
- Przed wysłaniem zestawienia sprawdź status **Kompletna** i pobierz PDF.
- W przypadku starszych wysyłek zwracaj uwagę na oznaczenie **Dane bieżące**.

> Zestawienie w systemie jest praktycznym dokumentem pomocniczym do ewidencji. Sposób rozliczenia w BDO warto potwierdzić z osobą odpowiedzialną za rozliczenia środowiskowe lub księgowość.

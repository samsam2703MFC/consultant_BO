## 🎯 Główne funkcje (TL;DR)

### Wyszukiwanie produktów 🔍
```
1. Wpisz: "bague"
2. Zobacz wyniki (live)
3. ↓↑ aby nawigować
4. Enter aby wybrać
✅ Produkt wybrany w 3 sekundy!
```

### Dodawanie do zamówienia ➕
```
1. Wyszukaj produkt (↑)
2. Wprowadź ilość: 10
3. Kliknij "Dodaj" (lub Ctrl+Enter)
✅ Suma zamówienia aktualizuje się automatycznie!
```

### Keyboard Shortcuts ⌨️
- **Ctrl+K** - Focus na wyszukiwarkę
- **↓↑** - Nawigacja w wynikach
- **Enter** - Wybierz/Potwierdź
- **Ctrl+Enter** - Dodaj produkt
- **Escape** - Zamknij dropdown

## 🆘 Szybka pomoc

### Problem: Nie widzę produktów w wyszukiwaniu
**Rozwiązanie**: Wpisz minimum 2 znaki (np. "ba")

### Problem: Nie mogę dodać produktu
**Rozwiązanie**: Sprawdź czy:
- ✅ Produkt został wybrany (niebieska ramka)
- ✅ Ilość jest większa od 0

### Problem: Suma się nie oblicza
**Rozwiązanie**: Odśwież stronę (F5)

### Problem: Wyszukiwanie nie działa
**Rozwiązanie**: 
1. Sprawdź console (F12)
2. Wyczyść cache przeglądarki
3. Skontaktuj się z supportem

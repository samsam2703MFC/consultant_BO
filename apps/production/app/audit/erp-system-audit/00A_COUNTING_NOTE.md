# Nota o liczeniu funkcjonalności

Podsumowanie wykonawcze zachowuje wczesny przekrój **42 funkcji biznesowych**. Po rozbiciu funkcji pomocniczych i technicznych (konfiguracja, integracje i obserwowalność) finalny katalog oraz macierz zawierają **50 wierszy**. Autorytatywny rozkład pełnego katalogu to: F0=6, F1=11, F2=14, F3=17, F4=2, F5=0. W końcowym odbiorze należy używać liczby 50; liczba 42 służy jedynie jako węższy przekrój biznesowy.

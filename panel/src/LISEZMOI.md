# Le cockpit franchisé — le dossier

Regroupé le 15/11/2026 (demande : « regrouper tout le nouveau cockpit franchisé dans un dossier » ; choix : un dossier
dédié, un seul déploiement). Le cockpit franchisé est le **dashboard magasin** : ce que voit un magasin ou un franchisé,
connecté par son code ou la console. Le cockpit du siège et lui partagent la même API (`shared/public/api/index.php`), la même
base et le même déploiement.

## Où est quoi

| Partie | Dossier |
|---|---|
| L'écran (vanilla JS, sans compilation) | `panel/public/dashboard/` : `index.html`, `dashboard.js` (le rail, la barre, les vues), et un module par page autonome — `offres.js`, `marketing.js`, `reseaux.js`, `tresorerie.js`, `catalogue.js`, `api-index.js` (+ leurs `.css`) |
| Les modules serveur propres au franchisé | `panel/src/` (ci-dessous) |
| Le code partagé avec le siège | `src/` : l'accès (`acces.php`), l'ERP (`erp_api.php`, `panel_api.php`), les ventes, le résultat, les tâches, la fidélité… |
| L'index de l'API du dashboard | `panel/public/dashboard/api-index.json`, généré par `panel/tools/dashboard-api-index.py` ; le bouton « API » de la barre l'affiche, avec les appels de la session |

## Les règles

- **L'accès** : une session de magasin n'ouvre que les préfixes de `ACCES_FRANCHISE` (`shared/src/acces.php`), et le magasin
  de la requête (`shop`…) doit être le sien. Une route qui désigne un objet par son numéro (une offre, un post) vérifie
  elle-même qu'il est de ce magasin. L'index de l'API signale les chemins qu'une session de magasin se verrait refuser
  en mode « console » (aujourd'hui : `/marketing/avis`, `/meta`, `/produits`).
- **Les autres portails** : par leur API, jamais leurs tables (`CLAUDE.md` à la racine). Le Marketing : `mar_api_url` et
  `erp_jeton_service` d'`erp_cles` (Mon catalogue, Réseaux sociaux). L'ERP TF Buddy : `ErpApi` (compte admin).
- **Le déploiement** : celui du cockpit (`shared/bin/deploy.sh`, `deploy.trigger`). `shared/bin/deploy.sh`, `shared/bin/tests.php`,
  `panel/bin/tests_primes.php`, `shared/bin/carte_sources.php` et `marketing/src/marketing_sources.php` lisent `panel/src/*.php` comme
  `src/*.php`.
- **Les tests** : `php bin/tests_tresorerie.php`, `php bin/tests_pnl_ht.php`, `php bin/tests_temps_morts.php`, `php bin/tests_boite_mail.php`, `php bin/tests_boite_pilote.php` ; l'espace boutique intégré est
  testé côté Marketing (`api/social/bin/tests.php`, cas « cockpit »).

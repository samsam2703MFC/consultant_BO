Les ventes croisées nouveau

Une vente croisée : un ticket à 2 lignes ou plus (deux produits différents ; trois croissants font une ligne). Le compteur du jour est dans l’app ; la prime se joue sur le taux du mois, pas sur le nombre brut, pour ne pas primer les gros horaires.
